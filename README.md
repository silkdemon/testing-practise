# Форма — магазин для практики автотестов

Учебный интернет-магазин: каталог, регистрация и вход, гостевая корзина,
перенос корзины при входе и оформление заказа без оплаты.

- [Фронт: React + TypeScript](front/README.md).
- [Бэк: Go + PostgreSQL, запуск и тесты](back/README.md).
- [OpenAPI](back/openapi.json).
- [Архитектура бэка](back/ARCHITECTURE.md).

Локальные адреса: фронт `http://127.0.0.1:5173`, API
`http://127.0.0.1:8080/api`. Демо-аккаунт: `demo@example.com` / `Demo12345`.

PostgreSQL запускается через `compose.yaml`; данные остаются в Docker volume.
Настройки подключения находятся в локальном `.env`, пример — `.env.example`.
Фронт переключается между настоящим API и MSW через `front/.env.local`.
Подробные команды и явный сброс учебных данных описаны в инструкции бэка.

## Весь проект одной командой

Нужен только запущенный Docker с Compose. Используется отдельный файл
`compose.full.yaml`: фронт собирается и раздаётся через Nginx, запросы `/api`
передаются Go-сервису, данные сохраняются в PostgreSQL.

Из корня проекта с существующим `.env`:

```sh
docker-compose -f compose.full.yaml up -d --build --wait
```

Если `.env` ещё нет, скопируйте `.env.example` и задайте `POSTGRES_PASSWORD`
(например, случайную hex-строку). Для этого Compose остальные переменные из
обычного `.env` не нужны: внутренний адрес базы и настройки фронта заданы в файле.
При установленном плагине Compose используйте `docker compose` вместо `docker-compose`.

Магазин: **http://127.0.0.1:3000**. API: **http://127.0.0.1:3000/api**.
Открывайте адрес с `127.0.0.1`, соответствующий настройке CORS.
Миграции и заполнение отсутствующими демо-данными выполняются автоматически.
Демо-вход: `demo@example.com` / `Demo12345`.

Этот вариант использует отдельный проект `forma-full` и volume
`forma-full_postgres-data`. Данные из обычного `compose.yaml` не переносятся;
оба варианта могут работать одновременно. Наружу опубликован только порт фронта.
Локальный `front/.env.local` не попадает в образ; контейнер всегда использует
настоящий API. Изменения кода применяются повторной командой запуска с `--build`.

```sh
# Состояние и логи:
docker-compose -f compose.full.yaml ps
docker-compose -f compose.full.yaml logs -f

# Остановка с сохранением данных:
docker-compose -f compose.full.yaml down
```

Для другого порта добавьте `FRONT_PORT=3001` в `.env`; сайт и API станут доступны
на `http://127.0.0.1:3001`. Параметр `down -v` дополнительно удалит данные этого
варианта запуска.
